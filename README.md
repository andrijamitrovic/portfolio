# Andrija Mitrović Portfolio

Minimal React portfolio and web resume based on my PDF CV.

Live site: https://andrijamitrovic.github.io/portfolio/

## Features

- Web version of my resume
- Downloadable PDF resume
- Links to GitHub, projects, and source code
- Light/dark theme toggle
- Minimal resume-style layout

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- lucide-react
